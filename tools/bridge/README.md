# 自动化测试桥接器 — 使用说明

## 这是什么？

这是一个让**云电脑**和**本地电脑**安全通讯的小工具。

- **云电脑**（云端）：编译 APK、分析日志的地方
- **本地电脑**（你面前的电脑）：连接手机、抓取 adb 日志的地方

它们通过 MQTT（一个公共消息服务器）进行通讯，每次连接都需要密钥验证，确保只有你本人可以连接。

## 1. 准备工作

### 你需要安装的软件

**两台电脑都需要：**

| 软件 | 去哪里下载 | 怎么验证已安装 |
|------|-----------|--------------|
| Python 3.8+ | https://www.python.org/downloads/ | 打开 cmd 输入 `python --version` |
| pip | 安装 Python 时自带 | 打开 cmd 输入 `pip --version` |

**本地电脑额外需要：**

| 软件 | 去哪里下载 | 怎么验证已安装 |
|------|-----------|--------------|
| ADB | Android Studio SDK/platform-tools/ | 打开 cmd 输入 `adb --version` |
| 手机 USB 驱动 | 手机品牌官网 | `adb devices` 能看到设备 |

### 安装 Python 依赖库

```bash
pip install paho-mqtt
# 或（如果 pip 不行）：
python -m pip install paho-mqtt
```

## 2. 云电脑端（云端）

### 启动

```bash
cd 项目目录/tools/bridge/
python cloud_bridge.py
```

输出示例：

```
==================================================
  云电脑安全桥接器
==================================================
  会话 ID: e97c9822
  通讯密钥: 5WFL-JK9N-SS62
  MQTT Broker: broker.hivemq.com:1883
==================================================

等待本地电脑验证身份...
```

密钥每次启动都会新生成，只对当前会话有效。按 `Ctrl+C` 关闭。

---

## 3. 本地电脑端（你面前的电脑）

1. 把 `local_bridge.py` 复制到本地电脑
2. 运行 `python local_bridge.py`
3. 输入密钥，点击「同意」
4. 验证通过后，点击「发送日志」
5. 分析结果会自动显示

---

## 4. 完整通讯流程

```
云电脑                          本地电脑
  |                                |
  | 1. 启动 cloud_bridge.py       |
  | 生成密钥: 5WFL-JK9N-SS62      |
  |                                |
  | AI 告诉你密钥                |
  | -----------------------------> |
  |                                | 2. 启动 local_bridge.py
  |                                | 3. 输入密钥+点击同意
  | <----------------------------- | 4. 发送验证
  | 5. 验证通过                  |
  | -----------------------------> | 6. 显示已连接
  |                                | 7. 手机连电脑+发送日志
  | <----------------------------- | 8. adb 日志
  | 9. AI 分析并写入结果        |
  | -----------------------------> | 10. 显示分析结果
```

## 5. 常见问题

**Q1: paho-mqtt 未安装**

```bash
pip install paho-mqtt
```

**Q2: 找不到 adb 命令**

确认 ADB 在 PATH 中，或者在 cmd 中 `cd` 到 platform-tools 目录再运行。

**Q3: 未检测到设备**

- 检查 USB 连接
- 开启手机 USB 调试
- 第一次连接需要手机点击「允许」

**Q4: 验证超时**

- 检查密钥是否输入正确
- 检查网络连接
- 确认云端桥接器正在运行

---

## 6. 安全说明

- 每次启动生成一次性密钥，关闭即失效
- 只传输纯文本，不涉及二进制
- MQTT 主题使用密钥派生的会话 ID，无法预测
